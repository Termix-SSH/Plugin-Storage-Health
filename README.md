## Overview

Storage Health reads the drives, pools and arrays on your hosts and shows their health in a tab. Termix keeps a history of temperature and wear, logs every problem and sends an alert when a drive fails, a pool or array degrades, or a drive runs hot or wears out.

Read the [docs](https://docs.termix.site/plugins/storage-health) to set it up and use it.

<br />

## Features

- SMART and NVMe health, temperature, wear and bad sectors
- ZFS pools, mdadm arrays, btrfs filesystems and LVM thin pools
- Charts for 24 hours, 7 days and 30 days
- Alerts for failing drives, degraded pools and arrays, heat, wear and full thin pools
- A log of problems, self tests and scrubs for every host
- Start SMART self tests and scrubs from Termix
- A Host Metrics card, a dashboard card, signals and events for Operations and Automations

Problems with Termix itself (login, hosts, credentials, sharing, sync) go in the [Termix repo](https://github.com/Termix-SSH/Termix/issues/new/choose). Not sure where it goes? Open it there and it will be moved.
